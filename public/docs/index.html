Kunla documentation#

Kunla is a shared record of the work people and AIs do for a team, with one screen for the decisions that need a person. These guides explain how to run your own copy and how to use it day to day. Every Kunla also serves them as web pages at /docs/.

Guide For What it covers
Using Kunla Everyone: team leads, sales, marketing, data, management The ideas (workspaces, projects, tasks), the screens, statuses, reviews, waiting and continuous mode
Connect your AI Everyone who works with an AI Adding Kunla to Claude (web, desktop, phone), Claude Code, the kunla command line tool and other agents
Self-hosting Whoever runs Kunla for the team Deploying to Cloudflare, keeping data in the EU, sign-in, upgrades, backups, staging, and other hosting options

More detailed pages:

  • Codex and open-source agents (OpenCode, Goose, Aider, OpenHands)
  • Contributing to Kunla itself
  • The main README is the full reference: every setting, the GitHub integration, wake-up URLs and the list of tools agents can call
  • Maintainers: publishing the CLI to npm and PyPI

Don't want to run it yourself? Kunla Cloud at kunla.app is the hosted version of the same code.
